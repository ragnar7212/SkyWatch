# Skywatch 🌤️

A clean, no-nonsense weather app that tells you what the sky is doing so you don't have to look out a window yourself.

## Features
- Real-time weather search
- Clean layout that doesn't hurt your eyes
- Built with vanilla HTML, CSS, and JavaScript

## Setup
1. Clone this repo.
2. Create a `config.js` file in the root folder and add your API key like this:


   const apikey = "YOUR_API_KEY_HERE";
